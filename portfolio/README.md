# Project Portfolio

This portfolio shows the work behind my private and public GitHub repositories without
publishing source code or sensitive material. Each case study is intentionally limited to
facts that are safe to disclose: the problem, the engineering approach, the technologies,
the safety boundaries, and the current status.

## Competencies demonstrated across the work

### Full-stack and backend development

Python, Django, FastAPI, SQL, TypeScript, React, Next.js, REST-style APIs, command-line tools,
third-party integrations, background-style job workflows, and client-facing reports.

### Application security and privacy-aware engineering

Authorization gates, role-based access control, data minimization, secrets outside source
control, redacted reports, HTTP security-header and TLS checks, safe URL handling, testable
configuration, and explicit scope limits. This is defensive engineering — not an advertisement
for offensive security or penetration-testing services.

### QA, reliability, and delivery

Automated tests, static analysis, deterministic reports, GitHub Actions, browser checks,
release checklists, change control, documentation, Linux deployment foundations, and rollback
planning.

### WordPress and small-business web support

WordPress/WP-CLI, Docker/DDEV local environments, safe plugin and theme diagnostics, backup
and restore verification, multilingual QA, performance/security review basics, and
plain-language client reporting.

### Data, migration, and multilingual systems

SQL reconciliation, synthetic data demonstrations, read-only database access, privacy-safe
reporting, hreflang, canonical URLs, metadata checks, and Finnish/English website quality workflows.

## Safe disclosure policy

Private project code, production configuration, customer data, credentials, access URLs,
reports from real targets, and third-party provider keys are not published here. A project
being private does not mean it is unfinished; it means the implementation is handled with the
same confidentiality and security care expected in professional work.

For the complete inventory — including learning projects and work intentionally not marketed as
a production service — see the [project index](project-index.md).
